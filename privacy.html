Privacy Policy

Last updated: November 12, 2026

FU Uploader ("the tool") is a personal tool used only by the owner of one YouTube channel to manage that channel. This page explains what data the tool uses.

What the tool accesses

With the channel owner's permission, the tool uses the YouTube API Services to upload videos to the owner's own channel, edit their titles, descriptions, thumbnails, captions and playlists, and read the channel's own analytics (such as views and watch time).

How the data is used

The data is used only to publish the owner's videos and to review their performance. The tool does not collect data from viewers or from any other YouTube user.

Storage and sharing

The access token is stored privately in the owner's own encrypted storage and is never shared. The tool does not sell, rent or share any data with third parties.

Revoking access

The owner can revoke the tool's access at any time from the Google Account security settings: https://myaccount.google.com/permissions

YouTube and Google policies

This tool uses the YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
