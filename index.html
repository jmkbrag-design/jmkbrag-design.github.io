FU Uploader

A private publishing tool

FU Uploader is a personal tool used by a single channel owner to publish videos to their own YouTube channel. It uploads finished videos, sets titles, descriptions, thumbnails and captions, and reads the channel's own viewing statistics so the owner can review how each video performs.

The tool is not offered to the public, and it does not access any other person's account or data.
